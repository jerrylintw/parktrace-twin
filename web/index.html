DATA STRUCTURES IN ACTION

演算法運作實驗室

每個結構都對應真的停車資料，不是寫在簡報裡的名詞。

01

2D Array 二維陣列

依列 / 行儲存 A、B、C 區各 6 格車位。

索引 O(1) ・尋找可用車位 O(n)

          
02
Queue 先進先出
車位不夠時 Enqueue，出場後 Dequeue 補位。
deque 入隊 / 出隊 O(1)

          
03
Stack 後進先出
將事件 Push 到堆疊，再 Pop 顯示最近操作。
Push / Pop O(1) ・不刪除永久日誌

          
04
Doubly Linked List 雙向鏈結串列
每輛車都有 prev / next 指標，串接停放順序。
首尾插入 O(1) ・依車牌搜尋 O(n)

        

        
這個專案和一般停車場模擬有何差異？
我們分別保存 Assigned（資料庫分配車位） 和 Observed（攝影機或人工觀測車位）。兩者不同時直接標示衝突；每個事件另外保存一份狀態快照，讓你回放當時的車位變化。這些設計用於查出「有進場紀錄但車停錯格」等情形。
